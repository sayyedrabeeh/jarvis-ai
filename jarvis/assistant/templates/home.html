VI Assistant - Your Interactive Web Assistant

Django-powered virtual assistant that plays music across YouTube, Spotify, and more, answers questions from Wikipedia, searches the web, tells jokes, and opens popular websites—all without external APIs.

Access Platform

What VI Assistant Can Do

  • 01

    Multi-Platform Music Playback

    Play your favorite songs on YouTube, Spotify, SoundCloud, or Gaana. Just tell VI what you want to hear and which platform to use.

  • 02

    Wikipedia Knowledge Base

    Get quick answers to "who is" and "what is" questions using Wikipedia's extensive database of information.

  • 03

    Web Navigation & Search

    Open popular websites instantly or search the web. Access social media, entertainment platforms, shopping sites, and more with simple commands.

Getting Started

Click "Access Platform" to start using VI Assistant. Try commands like "Play Bohemian Rhapsody on Spotify" or "What time is it?"

No APIs Required

VI Assistant is built entirely using Python libraries like pywhatkit, wikipedia, and pyjokes. No API keys or complex setup needed!

Open Source

This project is open source and available on GitHub. Contributions are welcome!
